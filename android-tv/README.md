# YQXYY Android TV (independent from mobile)

This is a **native Android TV preview**. It combines the public Supabase `movie_library`
with the original R2-backed film list (82 records) and animation-learning series
via the existing /data JSON proxy. No Netlify deployment, phone APK update,
database schema change or R2 data change is required.

## Features
- Leanback launcher, landscape 10-foot dark interface and remote D-pad navigation.
- Poster shelves: Kids animation, documentaries, animation movies and stories.
- One card per series; seasons, episodes, next/previous episode.
- Media3 ExoPlayer HLS/MP4 playback with source switching and real subtitle
  track selection (off/auto/available tracks), plus configurable caption size.
- Optional external HTTPS WebVTT/SRT subtitle URLs carried as subtitle-type
  entries in the existing `playback_sources` array.
- On-screen errors for unavailable/unsupported streams; do not assume
  autogenerated third-party M3U8 links actually exist.

## Limitations of this preview
- Movie titles and original animation-story series are now listed alongside
  the dynamic Supabase catalogue. Opening an R2 animation series fetches its
  episode list on demand and plays supported HTTPS HLS/MP4 sources.
- **TV version only plays video**: Little Fox Read/Word/Quiz activities,
  authentication and progress sync are NOT yet implemented.
- Website embedded/iframe player sources cannot be decoded by native Media3.
- Chinese/English/bilingual choices require actual tracks; no synthetic
  translation. Subtitle time offset and dual-caption overlay are not yet built.
- Some Android forks (set-top boxes) may not support Android TV launcher banners.
- Play URLs are read from existing data; they are not uploaded to R2.

## Build
At the repository root:
```
node android-tv/tools/prepare-config.cjs
cd android-tv
gradle :app:assembleDebug
```
No secret key is used: `js/supabase-config.js` contains the website's public
publishable key, copied to an ignored generated asset. Do not commit secret keys.
Install `android-tv/app/build/outputs/apk/debug/app-debug.apk` on Android TV/Google TV
or a compatible Android box. Debug APK signature may change between CI runs.

GitHub Actions `Build YQXYY Android TV APK` publishes
`YQXYY-TV.apk` separately from the phone release.

## Data catalogue and Android-phone preview
- Original site's `data/movie-hub-catalog.json` and `data/movie-posters.json`
  supply existing film posters; movie direct HLS sources are resolved from
  `data/movies/<collection>/movies.json` when an individual film is selected.
- The animation-story shelf reads `data/series-list.json`; per-episode
  `data/<seriesId>/episodes.json` is fetched only upon opening that series.
- Source URL must be real HTTPS HLS/MP4; iframe URLs are not suitable for Media3.
- On compact phone landscape (<510dp tall), header/card spacing is reduced.
  Native Android TV on a large display keeps full-size artwork and focus rings.
- These data files remain hosted by the existing Netlify /data proxy to R2.
  No modification is made to Netlify, R2, or the phone app.
